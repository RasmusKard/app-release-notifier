    Interface IngestEvent

    The JSON body of a POST /ingest, signed with Standard Webhooks. A missing or bad signature, or a timestamp more than 5 minutes off, gets a 401. An invalid body gets a 400 with the reason. Unknown keys are ignored.

    interface IngestEvent {
        type: string;
        title: string;
        severity?: "info" | "success" | "warning" | "error";
        time?: string;
        body?: string;
        actor?: string;
        source?: string;
        fields?: { label: string; value: string }[];
        links?: { label: string; url: string }[];
        labels?: Record<string, string>;
    }

    type

    type: string

    The type routes match on: lowercase words joined by dots, such as update.published. Up to 100 characters.

    title

    title: string

    Up to 500 characters.

    severity

    severity?: "info" | "success" | "warning" | "error" = 'info'

    time

    time?: string

    When it happened, as an ISO 8601 date. When unset, the time it was received.

    body

    body?: string

    Plain text, may be multi-line. Up to 4000 characters; Slack shows the first 3000, Discord 2000 and Teams 1000.

    actor

    actor?: string

    Who triggered it. Up to 4000 characters.

    source

    source?: string = 'CI'

    Where it came from, shown in the message. Up to 4000 characters.

    fields

    fields?: { label: string; value: string }[]

    Up to 20, with labels up to 200 and values up to 3000 characters. Slack and Discord show the first 10, Teams the first 6.

    links

    links?: { label: string; url: string }[]

    Up to 10 http(s) links, with labels up to 200 characters. The first one also makes the title a link. Slack and Discord show the first 5, Teams the first 6. Discord drops URLs over 512 characters, Teams over 2048.

    labels

    labels?: Record<string, string>

    Labels routes match on, such as { "app": "myapp" }. Never shown. Values up to 200 characters.
