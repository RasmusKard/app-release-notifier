    Interface ConfigRoute

    Sends the events that match it to targets. Every matching route fires, and a target matched by several routes gets one message.

    interface ConfigRoute {
        types: string[];
        labels?: Record<string, string>;
        minSeverity?: "info" | "success" | "warning" | "error";
        targets: string[];
        mention?: boolean;
        silent?: boolean;
    }

    Properties

    types

    types: string[]

    Event types: exact names, or a prefix ending in * such as appreview.* or *. The built-in types are build.succeeded, build.failed, build.canceled, submit.succeeded, submit.failed, submit.canceled, build.processing_failed, testing.build.available, appreview.submitted, appreview.in_review, appreview.approved, appreview.rejected, appreview.withdrawn and release.live. An IngestEvent brings its own, such as update.published.

    labels

    labels?: Record<string, string>

    Labels the event must have, matched exactly: app (the app id), platform (ios or android), profile (the EAS build profile), track (the Google Play track), or those of an IngestEvent.

    minSeverity

    minSeverity?: "info" | "success" | "warning" | "error" = 'info'

    Drops events less severe than this, in the order info, success, warning, error.

    targets

    targets: string[]

    The ids of the targets to post to.

    mention

    mention?: boolean = false

    Pings the target's mention.

    silent

    silent?: boolean = false

    Posts without a push notification, on targets that support it (DiscordTarget).
