    Interface ConfigFile

    The config file: YAML, read at startup from the path given as the server's argument (config.yaml when none is), or from the STOREHERALD_CONFIG environment variable when it's set, for hosts that can't mount a file. An unknown key fails startup.

    "${VAR}" in a string value is replaced with the environment variable VAR, and startup fails when it's unset. Quote it: inside { ... } an unquoted ${VAR} is a YAML syntax error. Numbers and booleans may be strings, so they can come from "${VAR}" too. Relative paths resolve against the config file's folder, or the working directory for STOREHERALD_CONFIG.

    Properties

    port

    port?: number = 8080

    The port to listen on.

    stateStore

    stateStore?: string

    A path to a module exporting get(key) and set(key, value), named or on a default export, where the Google Play poller keeps the release states it has seen. Values are strings. get returns undefined when nothing is stored and throws on errors, which skips that poll. When unset, states are kept in memory and lost on restart.

    apps

    apps: Record<string, ConfigApp>

    The apps, by id. The id may contain a-z, 0-9 and -. It is in the webhook URLs (/eas/<id>, /asc/<id>) and is the app label routes match on.

    ascApi

    ascApi?: ConfigAscApi

    Adds the version number, the platform and a link to the app to App Store Connect messages. If the lookup fails, the message is sent without them.

    playApi

    playApi?: ConfigPlayApi

    The Google Play API credentials for every ConfigApp.play.

    ingest

    ingest?: ConfigIngest

    Enables /ingest.

    targets

    targets: (SlackTarget | DiscordTarget | TeamsTarget)[]

    Where messages are posted. At least one.

    routes

    routes: ConfigRoute[]

    Which events go to which targets. At least one.
